# 🐘 Мир Слоновых

Домашний видеопортал для детей. Работает по локальной Wi-Fi сети без интернета после установки.

## Запуск на Windows

1. Установите Python 3.12+ и Git for Windows.
2. Откройте командную строку и выполните:
   `git clone https://github.com/Afrodizzyak1/slonov-home.git`
3. В папке `slonov-home` скопируйте `config.example.json` в `config.json`.
4. Укажите в `config.json` реальную папку с мультфильмами. Например: `D:\Multiki` (в JSON нужны двойные обратные слеши).
5. Дважды нажмите **Запустить портал.bat**.
6. На ноутбуке откройте http://localhost:8000.

Для телефона в той же Wi-Fi сети: http://IP_НОУТБУКА:8000. IP можно узнать командой `ipconfig` (IPv4-адрес). При запросе брандмауэра разрешите Python только в частных сетях.

## Обновление

Остановите сервер, нажмите **Обновить портал.bat**, затем снова запустите портал. Интернет нужен для обновлений, но не для просмотра. `config.json` не отслеживается Git.

## Возможности v0.1

- Поиск и автоматическое обнаружение видео во вложенных папках
- Просмотр и перемотка, следующее видео
- Продолжение просмотра на том же устройстве
- Работа в локальной сети без облака

Браузеры могут не поддерживать MKV/AVI и отдельные кодеки. Рекомендуемый формат — MP4 H.264/AAC. Не открывайте порт 8000 в интернет: авторизации пока нет.
